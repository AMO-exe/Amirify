---
description: Build or query an amirify knowledge graph
---

Invoke the `amirify` skill immediately.

Pass the full `/amirify` argument string through unchanged.
If no arguments were supplied, treat the target path as `.`.

Examples:
- `/amirify`
- `/amirify src --update`
- `/amirify query "what connects auth to billing?"`

Do not answer from raw files before handing off to the `amirify` skill.
